You are given a portfolio optimization problem. You have 10 assets with these expected annual returns:
{returns}

The covariance matrix is:
{cov_matrix}

Find portfolio weights w_1...w_10 that:
- Minimize total portfolio variance (w^T Sigma w)
- Achieve an expected return of at least {target_return}
- Sum to 1
- Are all non-negative (no short selling)

You have access to one tool:

solve_qp(P, q, G=None, h=None, A=None, b=None, bounds=None) -> dict
    Computes a vector x that minimizes (1/2) x^T P x + q^T x
    subject to:
        G x <= h        (each row of G defines one inequality constraint)
        A x == b        (each row of A defines one equality constraint)
        bounds[i][0] <= x[i] <= bounds[i][1]   (per-coordinate bounds; None means unbounded on that side)
    P must be symmetric (P == P.T) with all eigenvalues >= 0, within numerical tolerance.
    Returns:
        {"status": "optimal" | "infeasible" | "unbounded" | "error",
         "x": list[float] | None,
         "objective": float | None,
         "message": str}

Return a single JSON object with one field: "weights", a list of 10 floats summing to 1.
Return only the JSON. Do not return any other text.
